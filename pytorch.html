PyTorch 实现代码

①~⑤ 五个步骤与上方动画的训练过程一一对应

import torch
import torch.nn.functional as F
torch.set_default_dtype(torch.float64)

# ① 张量：4 行样本，每行 2 个输入
x = torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
target = torch.tensor([[0.],[1.],[1.],[0.]])

# ② Parameter 表示这些数可由训练更新
W        = torch.nn.Parameter(torch.tensor([[2.,-2.],[-2.,2.]]))
b_hidden = torch.nn.Parameter(torch.tensor([-1.,-1.]))
v        = torch.nn.Parameter(torch.tensor([[3.],[3.]]))
b_output = torch.nn.Parameter(torch.tensor([-2.5]))
parameters = [W, b_hidden, v, b_output]
optimizer = torch.optim.Adam(parameters, lr=0.03)

for epoch in range(1, 301):
    optimizer.zero_grad(set_to_none=True)  # 清旧梯度
    hidden = torch.sigmoid(x @ W + b_hidden)
    logits = hidden @ v + b_output
    # ③ 损失：比较 logits 与 target
    loss = F.binary_cross_entropy_with_logits(logits, target)
    # ④ 自动求梯度：梯度写入 .grad
    loss.backward()
    # ⑤ 更新参数：Adam 读取梯度并改变参数
    optimizer.step()

with torch.no_grad():
    hidden = torch.sigmoid(x @ W + b_hidden)
    prob   = torch.sigmoid(hidden @ v + b_output)
print((prob >= 0.5).int().flatten().tolist())
  • ①数据：4 个 XOR 样本 x 和答案 target，float64 精度
  • ②参数：用 nn.Parameter 包装 W、b、v，交给 Adam 管理
  • ③损失：F.binary_cross_entropy_with_logits 直接吃原始分数，数值稳定
  • ④梯度：loss.backward() 自动把梯度写入每个参数的 .grad
  • ⑤更新：optimizer.step() 按梯度更新参数；每轮开头 zero_grad 清旧梯度
数据由 PyTorch 的 Adam 数值逻辑复现生成（eps=1e-8）· 最终概率 ≈ [0.029, 0.975, 0.975, 0.031] → 预测 [0, 1, 1, 0]
